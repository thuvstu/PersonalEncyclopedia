# glossary.md — 用語集

このアプリのコード・設計書・ガイドに出てくる用語をまとめる。対応する設計書節を併記する。

## データモデル

| 用語 | 説明 | 設計書 |
|---|---|---|
| **entry** | 知識のかたまりの最小単位。13型に統一されたテーブル | §5.1 |
| **CTI(Class Table Inheritance)** | 共通カラムを `entry` に置き、型ごとの追加情報を別テーブルに分ける設計 | §5.1 |
| **entry_definition** | 単語帳トラックの本体(term/definition/reading/field) | §5.8 |
| **search_document** | 検索専用の結合テキスト。FTS4 の元 | §7.2 |
| **connection** | 承認済みの entry 同士の関連(有向/無向、関係種別を持つ) | §5.5 |
| **connection_candidate** | 自動生成された関連候補(承認待ち) | §8.4 |
| **quiz_bank** | クイズの問題テーブル | §8 |
| **srs_review** | 復習の履歴テーブル(アルゴリズム非依存) | §5.8.5 |
| **embedding_job** | 埋め込み処理の状態管理テーブル(queued/running/done/failed) | §7.1 |
| **論理削除** | `deletedAt` を立てて消す方式。物理削除しない | §5.1 |

## 検索・AI

| 用語 | 説明 | 設計書 |
|---|---|---|
| **バイグラム** | 日本語を2文字ずつ重ねて区切る方式(例: `量子力学`→`量子 子力 力学`) | §7.2.1 |
| **FTS4** | SQLite の全文検索機能(外部トークナイザ不要) | §7.2 |
| **Embedding** | 文を固定次元(768)のベクトルにする変換 | §7.1 |
| **コサイン類似度** | 2つのベクトルの向きの近さ(1.0 で完全一致) | §7.1.1 |
| **RRF(Reciprocal Rank Fusion)** | 複数検索結果を「順位」だけで統合する方式。`1/(K+順位)` を足す | §7.2.2 |
| **Hybrid Search** | 全文検索+ベクトル検索を RRF で合算する検索 | §7.2 |
| **MRL(Matryoshka Representation Learning)** | ベクトルの次元を途中で打ち切っても使えるようにする技術。既定768 | §4.4 |

## 学習

| 用語 | 説明 | 設計書 |
|---|---|---|
| **SRS** | 間隔反復(Spaced Repetition)。復習タイミングを自動計算 | §8.5 |
| **SM-2** | 古典的な SRS アルゴリズム(グレード0〜5) | §8.5 |
| **FSRS** | 新しい SRS アルゴリズム(履歴テーブル設計により差し替え可能) | §8.8 |
| **repetitionCount** | 累積成功反復回数。アルゴリズム切替時に失わないための記録 | §5.8.5 |
| **多段階採点** | 完全一致→正規化→複数解答→数値→同義語→類似度の順に判定する採点 | §8.4 |
| **undeterminable** | 判定不能(例: 未知の元号)。誤答とは別扱い | §8.9 |
| **サバイバル形式** | 1問ミスで即終了するクイズ形式(連続正解数を記録) | §8.7.2 |
| **プレッシャーテスト** | 60秒制限で同一分野の全項目を漏れなく答える形式 | §8.7.2 |
| **速度ボーナス** | 正解かつ10秒未満で+最大50%。`answeredWithinMs` を利用 | §8.7.3 |

## システム

| 用語 | 説明 | 設計書 |
|---|---|---|

| **GAP-4 / GAP-5** | 過去の品質改善の実績 ID(スレッドセーフ化、和暦対応など) | §13 |
| **エコの3軸** | 金銭・時間・環境のコストを最小にする方針 | §16 |
