## 1. DEEP SPEC（`db/HsDeepAncient.kt` 冒頭 KDoc に正本）
定義カード本文は必ずこの 7 節を順に持つ:
`【定義】【数値】【体系】【論争】【最新】【誤解】【接続】`
- 【数値】検証可能な数字 + 出典の種類 / 【論争】A説 vs B説 + 証拠の現状 / 【最新】2015 年以降に通説が動いた点 / 【誤解】教科書・一般書の古い理解と修正 / 【接続】他教科への `[[リンク]]`
- Wiki = 講義本文（見出し・表・年表・図式・⚠️💡🔑）
- クイズ 5 種必須: 典型 / 間違えやすい / 難問（統合） / 目新しい（最新研究） / おもしろ（逸話・語源）
